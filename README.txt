CNEER 2026 — archivos para GitHub Pages

Sube TODOS estos archivos a la raíz del repositorio cneer-2026-registro:

- index.html
- logo.png
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- favicon-32.png
- manifest.json

No cambies los nombres.

iPhone/iPad:
1. Elimina el acceso anterior si ya lo habías agregado.
2. Abre la web en Safari.
3. Compartir > Añadir a pantalla de inicio.

Android:
1. Abre la web en Chrome.
2. Menú ⋮ > Instalar aplicación o Añadir a pantalla principal.
3. El nombre e icono se obtienen de manifest.json.

Importante:
La aplicación necesita conexión a internet porque utiliza autenticación de Google
y Apps Script Execution API. Por eso no se incluye caché/offline mediante service worker.
